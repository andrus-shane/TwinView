Architecture rules from the 2026-08-20 design review One board on the 40-pin header (the CAN FD HAT, configured spi1-1cs — the wiki's spi1-3cs steals the belt encoder's GPIO17). Sequent thermocouple board runs off-board on an I2C pigtail with its own 5V — never mid-stack (the 3-HAT stack is not physically or thermally viable). Skip the M.2 HAT+; boot from a USB 3 SSD. 05

CAN FD tap

Listening to the machine's CAN bus; two channels = two buses, or listen + inject.

2-CH CAN FD HAT
PrimaryIn stockPi 5: community-proven

Waveshare 2-CH CAN FD HAT (SKU 17075)

Dual MCP2518FD on SPI, mainline spi-mcp251xfd socketcan driver — no vendor driver. Use spi1-1cs, not the wiki's spi1-3cs — the 3-CS variant pinmuxes GPIO17 away, which is the belt encoder's channel A (verify with raspi-gpio get 16 17 18). Bring interfaces up listen-only, termination off — a tap that ACKs frames or emits error frames is an active bus disruptor. Vendor docs stop at Pi 4B; community reports (#6407, #6644) prove Pi 5 operation but note delayed-RX / SPI-overflow quirks under heavy periodic traffic.

dtparam=spi=on
dtoverlay=spi1-1cs
dtoverlay=mcp251xfd,spi0-0,interrupt=25
dtoverlay=mcp251xfd,spi1-0,interrupt=24

08

Safety-key relay — 12V loop, GPIO-driven

Remote key pull for fault-injection and stop testing. The surprise finding: the "obvious" boards aren't actually isolated.

8-ch relay module
PrimaryIn stockWiring-dependent

ProtoSupplies 8-ch 5V relay module (JD-VCC header)

True galvanic isolation is achievable — but it ships bypassed. 8 channels = key 1 + key 2 + future fault-injection lines. Inputs active-low.

$7.95 ProtoSupplies
Wiring it for actual isolation
  1. Remove the JD-VCC↔VCC jumper — as shipped it ties coil power to logic power, defeating the optos (the vendor says so on the product page).
  2. Power JD-VCC/GND from a separate 5V supply, not the Pi's 5V.
  3. Connect only VCC and INx to the Pi — do NOT connect the Pi's ground to the board GND. The board has a single ground net; sharing it silently defeats the isolation.
Review caveats — bench checks before trusting it Continuity-test the actual board's ground topology (reviewers disagreed on whether the recipe is achievable on every revision). Check drive levels: 3.3V GPIO against 5V VCC leaves ~1.7V across the opto LED — marginal on some modules; if so, drive INx via an MCP23017 I2C expander (~$9, also gives opto-buffered inputs for 12V key-state sensing). Bench-test fail-safe with the treadmill unplugged: power loss, reboot, and script kill must all land in "key out". And a hardware E-stop independent of the Pi/relay chain is required before any automated fault injection — the software watchdog can't help if the Pi hangs.

Bench essentials the silicon total hides

From the design review — estimated prices, not research-verified. The must-haves are pre-checked.

8× K-type probes + extension wire + mounting

Ungrounded-junction surface probes (~$10-18 ea), K-type extension wire (yellow +, red − — reversed polarity reads inverted), Kapton/thermal adhesive. The DAQ ships with zero probes; keep one channel on ambient.

~$130 est.

Powered USB 3 hub (per-port switchable)

Pi 5 USB budget is 600mA-1.6A total — 3+ dongles and a charging tablet blow it in every configuration. A uhubctl-capable hub doubles as a tablet-USB-power fault-injection actuator.

~$35 est.

Battery-powered handheld oscilloscope

Highest-ROI tool not on the list: is that bus CAN or UART, is that rail mains-referenced, key-loop polarity — answered on day one. Never put an earth-referenced USB instrument on a possibly-mains-referenced node.

~$180 est.

True-RMS clamp meter

Answers the open question that gates §7: what do the rails actually draw?

~$50 est.

Hardware E-stop + GFCI

Physical mushroom button in the motor kill circuit — required before automated fault injection; independent of the Pi/GPIO/relay chain.

~$45 est.

MCP23017 I2C expander

8 outputs to sink the relay inputs + 8 opto-buffered inputs for key/fault state sensing — the free-GPIO budget covers actuate or sense, not both.

~$9 est.

USB 3 SSD, 256GB+

Replaces the dropped M.2 kit; continuous CAN logging kills microSD cards.

~$35 est.

Pi 5 RTC battery

Isolated bench network — no NTP on boot.

~$5 est.

UPS for the Pi (different circuit from the DUT)

Treadmill start surge on a shared breaker kills the logger with the data.

~$60 est.

Wiring & protection: fuses for every tapped rail, ferrules, twisted pair, DIN rail/enclosure, machine-connector pigtails, labels

Pigtails for the machine's actual connectors are the biggest hidden bring-up time sink.

~$100 est.
Budget reality The review put the realistic gap between the silicon total and a working bench at $700-1200 — flag it now so the first purchase order doesn't arrive without a single thermocouple.
